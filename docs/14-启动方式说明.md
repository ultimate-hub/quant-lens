# 14 - 启动方式

> 这份文档只回答一件事：**怎么把软件打开**。
>
> 如果你拿到的是**免安装版**（`QuantLens.exe`），直接看第二节，不用装 Python。

---

## 一、从源码启动（需要 Python）

### 第一次：装依赖

双击 **`install.bat`**，等 3-8 分钟（要下载约 250MB，主要是 Qt 内核）。

它会做三件事：
1. 找系统里的 Python（找不到会提示你去装）
2. 建一个项目专用的虚拟环境 `.venv`
3. 把依赖装进去

### 之后：双击启动

双击 **`Launch.vbs`**（中文名 `启动.vbs` 是同一份东西）。

会发生什么：

```
双击 → （什么都不显示）→ 约 2 秒后 → 弹出「量镜 QuantLens」窗口
```

**没有黑窗口，没有浏览器，就是一个软件。**

如果 2 秒后没反应，看同目录下的 `运行日志.log`。

---

## 二、免安装版（拿到 zip 的情况）

1. 把 zip **解压到一个纯英文路径**，例如 `D:\QuantLens`
   - 不要放在 `C:\Program Files`（只读目录，虽然程序会自动把数据目录切到用户目录，但没必要给自己找麻烦）
   - 路径里尽量避免中文和空格 —— 虽然现在支持了，但能避就避
2. 双击 `QuantLens.exe`
3. 窗口直接出现

数据会存在：
- 程序目录下的 `data\`（如果可写）
- 否则自动切到 `%LOCALAPPDATA%\QuantLens\data\`

第一次启动会弹一次免责声明确认，点掉即可。

---

## 三、三种启动方式的区别

| 方式 | 命令 | 什么时候用 |
|---|---|---|
| **桌面窗口** | 双击 `Launch.vbs` / `QuantLens.exe` | 日常使用 |
| **只起服务** | `python serve.py 8765` | 调试、或者你想用浏览器打开 |
| **GitHub 版源码** | 跟第一节一样 | 你自己改代码时 |

`serve.py` 只起后端，不开窗口，然后你自己用浏览器访问 `http://127.0.0.1:8765`。
前端改了想立刻看效果，用这个最方便（改完刷新浏览器即可，不用重启）。

## 四、为什么不用「浏览器应用模式」了

早期版本试过调 Chrome / Edge 的 `--app` 参数，假装成一个独立窗口。放弃了，因为：

| 尝试 | 结果 |
|---|---|
| pywebview | pythonnet 在含中文的路径下加载失败 |
| Chrome `--app` | 156 版本之后这个参数失效了 |
| Edge `--app` | 系统里已经开着 Edge 时，新窗口被吞掉 |
| 打包后调系统 API 开浏览器 | 被 PyInstaller 的冻结环境保护拦住 |

**现在的做法**：把 Chromium 内核（QtWebEngine）直接嵌进程序进程里。不借别人的浏览器，自己带一个。

代价是体积大（约 300MB），换来的是「双击就开、不依赖系统装了什么」。

---

## 五、关窗口会怎样

**关窗口 = 程序整体退出**，后台服务一起停。

下次再双击，重新起一次（2 秒）。

如果你希望关窗口后服务继续跑（比如你在用浏览器调试），那就用 `python serve.py`，
那个进程要手动在任务管理器里结束，或者关掉它的命令行窗口。

## 六、常见问题

### 双击没反应

1. 先确认装过依赖：双击 `install.bat` 跑一遍
2. 看 `运行日志.log` 最后几行
3. 命令行里跑 `python desktop_qt.py`，能直接看到报错

### 提示找不到 Python

装 Python 时没勾 `Add Python to PATH`。重装一次，安装界面**第一个复选框要勾上**。

### 窗口打开但一片空白

按 `Ctrl + R` 刷新。如果还是空白，看 `运行日志.log` 里有没有「页面加载失败」。

### 端口被占用

程序会自动往后找空闲端口（8765、8766、8767…），日志里会写实际用的是哪个。
如果你手动起了 `serve.py` 又双击图标，可能同时跑两个实例 —— 关掉一个即可。

### 第一次启动特别慢

正常。要建数据库、灌概念库种子数据（49 个概念、136 只股票）。
之后启动都是 2 秒左右。
