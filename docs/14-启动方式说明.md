# 14 - 启动方式说明（最终方案）

> 这份文档解决一个问题：**怎么可靠地把软件打开**。
> 前面几版方案在你这台机器上都不稳定，这里是最终可用的做法。

---

## 一、怎么启动（就这一种方式）

**双击桌面上的「量化终端」图标**

或者双击这个文件：
```
D:\AgentLand\量化分析软件\quant-platform\启动.bat
```

会发生什么：
1. 弹出一个黑色窗口，显示 `[1/3] [2/3] [3/3]` 进度
2. 再弹出一个「Quant Terminal - Server」窗口（**这个不要关**）
3. 浏览器自动打开，显示界面
4. 第一个黑窗口可以关掉

**界面地址**：`http://127.0.0.1:8765`

建议把这个地址**加入浏览器收藏夹** —— 以后服务开着时，点收藏夹就能进，不用再走 bat。

---

## 二、如果浏览器没自动打开

不用重装、不用重试。**手动打开浏览器，地址栏输入**：

```
http://127.0.0.1:8765
```

页面就出来了。这是最后一道保险，一定有效。

---

## 三、怎么停止

关闭任务栏上的 **「Quant Terminal - Server」** 窗口即可。

（浏览器标签页直接关掉也行，服务会在后台继续跑，不影响下次使用。）

---

## 四、为什么不用双击 exe 了

这是本次排障的核心结论，记录一下免得以后重走弯路。

### 尝试过的 5 种方案

| 方案 | 结果 | 失败原因 |
|---|---|---|
| 1. pywebview 原生窗口 | ❌ | pythonnet 在**中文路径**下加载失败 |
| 2. exe + Chrome `--app` | ❌ | Chrome 156 起 `--app` 失效，命令被吞但不开窗口 |
| 3. exe + Edge `--app` + 独立 profile | ❌ | 独立 profile 目录有锁，Edge 起了但窗口不出现 |
| 4. exe 内 ShellExecuteW 调浏览器 | ❌ | **PyInstaller 冻结程序里 ShellExecuteW 被拦截**（普通 Python 里返回42正常） |
| 5. **bat + serve.py + `start url`** | ✅ | 普通 cmd 进程，`start` 必定打开默认浏览器 |

### 关键教训

**不要在打包后的 exe 里尝试启动外部程序**。
PyInstaller 的冻结环境会干扰子进程创建（PATH 污染、句柄继承、API 拦截）。
把"启动服务"和"打开浏览器"拆成两个普通进程，问题全部消失。

## 五、几个常见情况

### Q：黑窗口一闪就没了？
说明 bat 里有语法错误。用记事本打开 `启动.bat` 检查，或者运行 `serve.py` 看报错：
```
python serve.py
```
会直接打印错误。

### Q：提示「[ERROR] Python runtime not found」
说明 Python 路径变了。用记事本打开 `启动.bat`，找到这一行改成实际路径：
```
set "PYEXE=C:\Users\杨\.dsh\dsh-runtimes\...\python.exe"
```

### Q：端口 8765 被占用
改 `启动.bat` 里的 `set "PORT=8765"` 为别的数字（如 8766），
浏览器地址也要跟着改。

### Q：页面打开是空白的
按 `Ctrl + F5` 强制刷新（清缓存）。

### Q：数据抓不到 / 提示网络错误
检查代理设置。bat 里已经清除了 `HTTPS_PROXY` 等变量，
如果你开着代理软件，可能需要关掉或调整规则。

## 六、文件说明

| 文件 | 作用 |
|---|---|
| `启动.bat` | **日常启动用这个** |
| `serve.py` | 只启动服务（bat 会调用它） |
| `desktop.py` | 旧的桌面启动器（打包 exe 用，现在不推荐） |
| `dist\量化终端\量化终端.exe` | 打包产物（自动开窗口不可靠，仅备份） |
| `运行日志.log` | exe 运行日志（排查用） |

## 七、下次要改进的话

如果以后想让"双击就有无地址栏的独立窗口"，正确的方向是：

1. **不用 PyInstaller**，改用 `pip install` 安装成命令行工具 + 桌面快捷方式
2. 或者用 **Tauri**（Rust + 系统 WebView），它不依赖 Python 打包
3. 或者接受现状：**浏览器标签页完全够用**，功能一模一样，只是多个地址栏

我的建议：**别折腾这个了**。浏览器标签页和独立窗口在功能上没有任何区别，
把时间花在策略和指标上更值。
