## 一、P1 多市场适配器

### 1.1 统一代码体系（`app/markets/symbols.py`）

跨市场最大的坑：同一个股票在每个数据源里写法都不同。

| 标准写法 | 腾讯 | Yahoo | 东财 secid |
|---|---|---|---|
| `600519.SH` | `sh600519` | `600519.SS` | `1.600519` |
| `000001.SZ` | `sz000001` | `000001.SZ` | `0.000001` |
| `00700.HK` | `hk00700` | `0700.HK` | `116.00700` |
| `AAPL.US` | `usAAPL.OQ` | `AAPL` | `105.AAPL` |

代码支持智能解析，以下写法都等价：
```
600519 / 600519.SH / sh600519 / SH600519 / 1.600519
```

**设计决策**：`Symbol` 是 `frozen dataclass`（不可变对象）。
好处：可以当字典的键（用于缓存），也不会被意外修改。

### 1.2 三个适配器

| 适配器 | 覆盖 | 职责 | 特殊处理 |
|---|---|---|---|
| `tencent.py` | A股/港股/美股 | K线主通道（A/HK）、快照备用 | 美股必须带交易所后缀 `.OQ/.N`，代码里自动探测并缓存 |
| `yahoo.py` | A股/港股/美股 | K线主通道（美股）、全球搜索 | 一次请求拿10年，无需分页 |
| `eastmoney.py` | A股/港股/美股 | 快照、A股基本面、中文搜索 | 数值缩放按市场不同、搜索噪音过滤 |

### 1.3 自动降级链（`registry.py`）

```python
KLINE_CHAIN = {
    "SH": [tencent, yahoo, eastmoney],   # 腾讯最快
    "HK": [tencent, yahoo],              # 腾讯最快
    "US": [yahoo, tencent, eastmoney],   # Yahoo 长历史
}
```

任一通道失败自动尝试下一个，全部失败才报错，并返回实际使用的数据源名称
（界面上可以标注"数据来源：腾讯"）。

### 1.5 开发中修复的 3 个真实 bug

| Bug | 现象 | 根因 | 修复 |
|---|---|---|---|
| 港股价格 ×10 | 腾讯控股显示 3876 元（实际 387.6） | 东财快照港股是 ×1000 存储 | 按市场区分缩放：A股÷100，港美÷1000 |
| 美股价格 ×10 | 苹果显示 3451 元（实际 345.15） | 同上 | 同上 |
| PE 显示 0 | 港股美股 PE 全是 0.0 | 东财对海外市场用 0 表示"无数据" | 加 `_nonzero()` 把 0 转成 None |

**还有一个搜索噪音问题**：搜 "apple" 会返回 `AAPL22 Apple Inc Notes 2022`（债券）。
已加过滤规则：名称含 Notes/Bond/票据，或代码形如"字母+2位数字"，一律剔除。

### 2.2 价格类指标清单（30+）

**收益与风险**
年化收益、年化波动率、最大回撤、**回撤持续期**、**回撤修复天数**、当前回撤、
下行波动率、**VaR(95%)**、**CVaR(95%)**、偏度、峰度、日胜率、盈亏比、**Ulcer疼痛指数**

**风险调整收益**
夏普、索提诺、卡玛、**Omega比率**

**相对基准**（需要基准数据）
**Beta**、**Alpha(Jensen)**、跟踪误差、信息比率、特雷诺、相对强弱(60日)

**动量与技术**
1/3/6/12月动量、**RSI(14)**、**MACD**（含金叉/死叉判断）、均线乖离率、
**52周价格位置**、**ATR(14)**、ATR占比

### 2.3 基本面指标（18）

估值：PE-TTM、PB、股息率、**PEG**（=PE/净利增速）、市值
盈利：ROE、ROIC、毛利率、净利率、经营现金流/净利润
成长：营收同比、净利同比
健康：资产负债率、流动比率、速动比率
每股：EPS、BPS

### 2.4 评分引擎的核心设计：可降级

**问题**：A股有完整基本面，美股只有价格数据。
如果缺数据就记 0 分，美股永远垫底，这不公平也不真实。

**解法**：只在**有数据的维度**上加权平均（权重重新归一化）。

实测（均衡型）：
```
600519.SH  覆盖 5/6 维度  →  估值22.2% 成长22.2% 质量22.2% 动量16.7% 风险16.7%
00700.HK   覆盖 3/6 维度  →  估值40.0% 动量30.0% 风险30.0%
```

权重自动从 20/20/20/15/15 变成 40/30/30，保证跨市场可比。

### 2.5 八套分析模式（实测对比）

茅台在 8 种模式下的得分：

| 模式 | 综合分 | 等级 |
|---|---|---|
| 质量型 | 66.7 | 良好 |
| 红利型 | 61.1 | 一般 |
| 低波型 | 60.6 | 一般 |
| 价值型 | 58.1 | 一般 |
| 均衡型 | 57.0 | 一般 |
| 动量型 | 55.5 | 一般 |
| 成长型 | 54.6 | 一般 |
| 困境反转型 | 50.1 | 一般 |

**读法**：茅台的维度分是 估值43 / 成长38 / 质量94 / 动量55 / 风险54。
质量极高但成长弱、估值不便宜，所以"质量型"下得分最高 —— 这完全符合事实。

### 2.6 三只标的实测对比

| 标的 | 年化 | 波动 | 最大回撤 | 夏普 | 综合分 | 看点 |
|---|---|---|---|---|---|---|
| 贵州茅台 | 20.92% | 32.99% | -51.30% | 0.57 | 57.0 | 质量94.5 但成长仅37.5 |
| 腾讯控股 | 3.11% | 37.27% | -73.80% | 0.03 | 42.0 | 三年熊市，动量32 |
| 苹果 | 32.93% | 30.54% | -33.36% | 1.01 | 51.6 | 动量79.8 但估值仅19（PB 46.9） |

**这三行数据本身就说明了评分系统的价值**：
- 茅台质量最好但成长停滞 → 得分中等
- 苹果涨得最猛但估值极贵 → 得分中等
- 腾讯回撤 74% → 得分最低

没有一只"完美"的股票，这符合真实市场。
