## 一、P5 新闻引擎

### 1.1 四个新闻源

| 源 | 类型 | 实测 | 特点 |
|---|---|---|---|
| 东方财富搜索 | 关键词检索 | 搜"固态电池"命中 3474 条 | 中文财经最全，支持任意关键词 |
| 华尔街见闻 RSS | 全量订阅 | 64 条/次 | 深度财经，质量高 |
| 新浪 7x24 | 实时快讯 | 50 条/次 | 突发消息最快 |
| Google News | 全球英文 | 100 条/次 | 海外标的首选 |

### 1.2 聚合流程

```
关键词
  → 四源并发抓取（约3秒，共约139条）
  → 相似标题去重（SequenceMatcher 阈值0.82）
  → 时间过滤（默认近7天）
  → 相关性排序（标题命中×3 + 摘要命中×1 + 时效加分 + 来源权重）
  → 板块映射
  → 缓存6小时
```

**实测效果**：139 条原始新闻 → 去重后 20 条，耗时 3.04 秒。
第二次查询走缓存：**0.004 秒**（快 760 倍）。

### 1.3 板块映射表（30个板块）

公开数据源没有"关键词→A股板块"的映射，只能自己维护。

```
"固态电池" → 命中词：固态电池/半固态/全固态
           → 代表个股：宁德时代、国轩高科、欣旺达、孚能科技
"人工智能" → 命中词：AI/人工智能/大模型/算力/GPU
           → 代表个股：科大讯飞、中科曙光、中际旭创、寒武纪
```

覆盖：半导体、固态电池、锂电池、人工智能、机器人、光伏、储能、
新能源汽车、白酒、医药、银行、券商、保险、房地产、消费电子、通信、
军工、有色金属、煤炭、石油石化、电力、食品饮料、家电、汽车零部件、
农业、基建、交运、传媒游戏、计算机、港股科技。

### 1.4 AI 归纳 + 规则引擎兜底

**AI 版本**输出结构化情报：

```json
{
  "overall_sentiment": "利好",
  "sentiment_score": 62,
  "summary": "固态电池产业化提速，机器人应用率先落地，产业链公司受关注",
  "key_events": [
    {"event": "小鹏机器人专用固态电池小批量下线",
     "impact": "标志固态电池进入量产验证阶段",
     "sectors": ["固态电池","机器人"], "sentiment": "利好"}
  ],
  "hot_sectors": ["固态电池","机器人","锂电池"],
  "related_symbols": [{"symbol":"300750.SZ","name":"宁德时代","reason":"..."}],
  "credibility": 0.72
}
```

**关键校验**：`related_symbols` 必须是系统提供的板块成分股，AI 编造的代码直接丢弃。
这和个股分析里的"目标价必须在候选里"是同一个防幻觉思路。

**规则引擎兜底**（无 AI 时）：
```
正向词库 25 个：利好/上涨/涨停/突破/增长/超预期/中标/获批...
负向词库 25 个：利空/下跌/跌停/跌破/下滑/亏损/减持/处罚...
情绪分 = (正向命中 - 负向命中) / 总命中 × 100
可信度固定 0.3（明确告诉用户这是粗糙结果）
```

实测：固态电池 → 利好 55 分，命中"涨停/领涨/上涨/创新高/增长/景气"等正向词。

## 三、P8 桌面应用

### 3.1 pywebview 方案

```
启动 → 后台线程跑 FastAPI（自动找空闲端口）→ 等健康检查通过
     → 开原生窗口加载 http://127.0.0.1:端口 → 关闭窗口即退出
```

**为什么不用 Electron**：纯 Python、无需 Node 构建链、体积小、
用系统自带 WebView2 内核。

**自动找端口**：默认 8765，被占用就往后试 30 个，避免和其他程序冲突。

### 3.2 实测结果

```
✅ 服务已就绪: http://127.0.0.1:8765
窗口标题: 量化终端 v2
窗口尺寸: 1424x941
渲染: 正常（截图见 docs/images/v2-desktop.png）
```

### 3.3 打包

```powershell
python build_exe.py
```

**选择 one-folder 而不是 one-file**：
1. 启动快（one-file 每次启动要解压几十MB到临时目录，等5-10秒）
2. 杀毒软件误报少（one-file 的自解压行为很像病毒）
3. 便于替换资源（改页面不用重新打包）

**打包时踩的坑**：
- uvicorn 的循环/协议实现是动态导入的，必须 `--hidden-import` 显式声明
- pywebview 在 Windows 上走 EdgeChromium，需要额外声明 hidden-import
- **启动器里不能用字符串导入**（`uvicorn.Config("app.main:app")`），
  打包后无法动态导入，必须传 app 对象
