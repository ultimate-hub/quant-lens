# 01 - 环境搭建

> 目标：从一台干净的 Windows 机器，到能跑起来。约 10 分钟。

---

## 一、需要什么

| 项 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 / 11 | 目前只支持 Windows（用到 DPAPI 加密和 .vbs 启动脚本） |
| Python | **3.10 或更高** | 3.11 / 3.12 都测过 |
| 磁盘 | 约 1.5 GB | 依赖 250MB + Qt 内核 + 数据缓存 |
| 网络 | 能访问国内镜像源 | 装依赖用清华源，不需要翻墙 |

> 如果你拿到的是免安装版（`QuantLens.exe`），**这一整篇都不用看**，直接双击 exe。

---

## 二、装 Python

去 https://www.python.org/downloads/ 下载 3.10 以上版本。

**安装时第一个界面底部有一个复选框：`Add Python to PATH` —— 必须勾上。**

不勾的后果：命令行里敲 `python` 提示「不是内部或外部命令」，后面所有步骤都会失败。

验证：

```powershell
python --version
```

输出版本号就对了。

> ⚠️ 如果你装的是**微软商店版** Python，可能出现 `ensurepip is not available` 这类问题。
> 建议改用 python.org 的官方安装包。

---

## 三、装依赖

双击项目根目录的 **`install.bat`**。

它会做三件事：

```
[1/2] 创建虚拟环境 .venv
[2/2] 安装 requirements.txt 里的依赖（走清华源）
```

首次约 3-8 分钟，主要时间花在下载 Qt 内核（约 130MB）。

### 为什么用虚拟环境

把依赖装进项目自己的 `.venv` 文件夹，不污染系统的 Python。
以后想删掉，直接删 `.venv` 文件夹就行，系统里什么都不留。

### 手动装（install.bat 失败时）

```powershell
cd 项目目录
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

## 四、验证装好了

```powershell
.venv\Scripts\python.exe -c "import fastapi, pandas, PyQt6.QtWebEngineWidgets; print('依赖齐全')"
```

输出 `依赖齐全` 就成功了。

再跑一遍测试：

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -q
```

应该看到 `Ran 59 tests ... OK`。

## 六、依赖里各是干什么的

| 库 | 作用 | 大小 |
|---|---|---|
| pandas / numpy | 表格与数值计算（金融分析的事实标准） | ~60MB |
| requests | 抓行情、调 AI 接口 | ~1MB |
| fastapi / uvicorn | 本地服务，把 Python 函数变成 HTTP 接口 | ~10MB |
| **PyQt6 / QtWebEngine** | 独立窗口 + 内嵌 Chromium 内核 | ~130MB |

### 为什么依赖里没有 scipy / sklearn

项目刻意保持依赖精简。需要的统计功能都是自己实现的：

- GARCH(1,1) 波动率 → `app/analytics/garch.py`（方差目标法 + 网格搜索，纯 numpy）
- 蒙特卡洛模拟 → `app/analytics/forecast.py`
- 各项技术指标 → `app/analytics/*.py`

**少一个依赖，就少一个「装不上」的环节。**

## 七、常见问题

### pip 装包超时 / 卡住

先确认用的是国内镜像源（install.bat 里已经写了清华源）。如果还是慢：

```powershell
.venv\Scripts\python.exe -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 提示 `pip` 版本过旧

```powershell
.venv\Scripts\python.exe -m pip install --upgrade pip
```

### 代理软件导致装不上包

如果你的机器开着代理（Clash / V2Ray 之类），pip 可能会走代理然后超时。
临时关掉代理，或者：

```powershell
$env:HTTP_PROXY=""; $env:HTTPS_PROXY=""; $env:ALL_PROXY=""
```

### PyQt6 报 `DLL load failed while importing QtWebEngineWidgets`

**版本不匹配**。`PyQt6` 和 `PyQt6-WebEngine` 必须版本一致。

`requirements.txt` 里已经锁死了版本：

```
PyQt6==6.11.0
PyQt6-Qt6==6.11.2
PyQt6-WebEngine==6.11.0
PyQt6-WebEngine-Qt6==6.11.2
```

不要改成 `PyQt6>=6.11` —— 那样会装到 6.12，而 WebEngine 最新只到 6.11，直接崩。

### 装完了但还是启动不了

看项目根目录的 `运行日志.log`，最后几行通常是真正的原因。
看不懂就把内容发到 issue 里（记得先删掉 API Key）。
