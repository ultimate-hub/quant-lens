# 05 - 运行手册

> 面向开发者 / 想改代码的人。只想用软件的话看 [14-启动方式说明](14-启动方式说明.md)。

---

## 一、三种跑法

| 方式 | 命令 | 用途 |
|---|---|---|
| **桌面窗口** | `python desktop_qt.py` | 就是日常用的那个窗口 |
| **只起服务** | `python serve.py 8765` | 改前端时用，刷浏览器就能看效果 |
| **跑测试** | `python -m unittest discover -s tests -q` | 改完逻辑先跑这个 |

> 所有命令都建议用项目自己的虚拟环境：
> `.venv\Scripts\python.exe <命令>`

---

## 二、只起服务（改前端最方便）

```powershell
cd 项目目录
.venv\Scripts\python.exe serve.py 8765
```

输出：

```
==========================================================
  量镜 QuantLens 服务端
==========================================================
  数据库就绪
  服务地址: http://127.0.0.1:8765
  接口文档: http://127.0.0.1:8765/docs
==========================================================
```

然后浏览器打开 `http://127.0.0.1:8765`。

**前端改动不需要重启服务** —— `static/app/` 下的文件是每次请求实时读的，
改完刷新浏览器即可。只有改 Python 代码才需要重启。

想换端口就改数字：`serve.py 8790`。

---

## 三、桌面窗口

```powershell
.venv\Scripts\python.exe desktop_qt.py
```

它的行为：
1. 建库
2. 从 8765 开始找空闲端口
3. 后台线程起 uvicorn
4. 等 `/api/v2/ping` 通
5. 开 QtWebEngine 窗口加载页面
6. 关窗口时一起退出

日志写到项目根目录的 `运行日志.log`（因为是窗口程序，没有控制台）。

---

## 四、日志怎么看

`运行日志.log` 每次启动都会往后追加。正常情况下最后几行长这样：

```
[20:41:54] 量镜 QuantLens 启动中…
[20:41:54] 数据库就绪
[20:41:55] 本地服务端口 8765，等待就绪…
[20:41:56] 服务就绪
[20:41:59] 窗口已显示
[20:41:59] 页面加载完成
```

**哪个环节停住，问题就在哪里**：

| 停在 | 说明 |
|---|---|
| `数据库就绪` 之前 | 数据库建不起来，看 `data/` 目录权限 |
| `服务就绪` 之前 | 端口全被占用，或者 uvicorn 起不来 |
| `窗口已显示` 之前 | Qt 初始化失败（多半是 PyQt6 版本不匹配） |
| `页面加载完成` 之前 | 页面加载失败，通常是 8765 端口上有别的东西 |

## 五、跑测试

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -q
```

现有 59 个测试，覆盖：

| 文件 | 覆盖内容 |
|---|---|
| `tests/test_indicators.py` | 13 个：基础指标边界值 |
| `tests/test_analytics.py` | 24 个：评分、锚点、基本面降级 |
| `tests/test_extended.py` | 22 个：扩展指标、统计特征 |

**改了计算逻辑一定要补测试。** 这些指标算错了不会报错，只会给你一个错数，
没有测试兜底根本发现不了。

## 六、接口文档

服务跑起来后访问 `http://127.0.0.1:8765/docs`。

FastAPI 自动生成的，可以直接在页面上点「Try it out」发请求。
调接口的时候比翻代码快。

主要接口：

| 路径 | 说明 |
|---|---|
| `GET /api/v2/analyze/{symbol}` | 完整分析（76 指标 + 评分 + 锚点 + AI） |
| `GET /api/v2/outlook/{symbol}` | 走势推演 + 配仓建议 |
| `GET /api/v2/screen` (POST) | 批量筛选 |
| `GET /api/v2/concepts` | 概念库 |
| `GET /api/v2/news?q=` | 新闻聚合 |
| `GET /api/v2/library` | 市场百科 |

## 七、打包 exe

```powershell
.venv\Scripts\python.exe build_exe.py
```

产物在 `dist/QuantLens/`，整个文件夹压缩成 zip 就是免安装版。

首次约 5-10 分钟，主要是收集 Qt 的资源文件。

脚本会自动检查这四个关键文件有没有打进去：

- `QtWebEngineProcess.exe`（渲染进程，缺了页面打不开）
- `qtwebengine_resources.pak`
- `icudtl.dat`
- `static/app/index.html`

**少任何一个，打出来的 exe 都是坏的**（而且是那种"能启动、白屏"的坏法，最难查）。

## 八、数据存在哪

| 内容 | 位置 |
|---|---|
| SQLite 数据库 | `data/quant.db` |
| AI 渠道密钥 | 同一个库，用 Windows DPAPI 加密 |
| 行情缓存 | 同一个库 |
| 运行日志 | `运行日志.log` |

如果程序目录不可写（比如装在 `C:\Program Files`），会自动切到：

```
%LOCALAPPDATA%\QuantLens\data\
```

日志里第一行 `数据目录: ...` 会写清到底用的哪个。**换电脑时，想带走配置就拷这个目录。**

## 九、重置

想从头来过（清空所有候选池、概念、AI 配置）：

```powershell
Remove-Item data -Recurse -Force
```

下次启动会重新建库、重新灌概念库种子。

只想重置某个东西：

- 概念库 → 概念库页面右键删除（内置的删不掉，可以改成分股）
- 候选池 → 候选池页面删除
- AI 渠道 → 设置页删除

## 十、常见开发问题

### 改了 Python 代码没生效

uvicorn 默认不开热重载（会拖慢启动）。手动重启 `serve.py`。

### 改了前端没生效

浏览器缓存。`Ctrl + F5` 强制刷新。

### 端口占用

```powershell
Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
  Where-Object { $_.CommandLine -like "*serve.py*" -or $_.CommandLine -like "*desktop_qt*" } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```

⚠️ 注意要**同时匹配 `desktop_qt`** —— 桌面窗口也会占端口。
只匹配 `serve.py` 的话，你以为杀干净了，其实旧进程还在跑旧代码，
然后你会花半小时怀疑「为什么改了没生效」。（真的踩过。）
