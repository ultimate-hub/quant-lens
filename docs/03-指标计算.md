## 零、统一的输入约定

所有指标函数的输入都是同一个东西：

```
s = 一个 pandas.Series（带日期索引的净值序列）
    2024-01-02    1.0000
    2024-01-03    1.0200
    2024-01-04    1.0150
    ...
```

> pandas.Series 可以理解为"带标签的一列数字"，标签是日期。
> 这是金融时间序列的标准数据结构。

## 一、基础概念：为什么一切从"收益率"开始

### 日收益率

```
今日收益率 = 今日净值 / 昨日净值 - 1
```

例子：昨天 1.00 → 今天 1.02，收益率 = 1.02/1.00 - 1 = **+2%**

**为什么要转成收益率？**
净值本身不能横向比较：A 基金净值 1.0，B 基金净值 3.5，谁涨得好？看不出来。
收益率是"标准化"后的数字，任何基金都能直接比。

代码：
```python
rets = nav.pct_change(fill_method=None).dropna()
```

> `fill_method=None` 是 pandas 3.0 的要求：遇到缺失值不要自动填充。
> 金融数据里"填充"是危险的（会凭空造出收益），宁可丢掉。

---

## 二、收益类指标

### 1. 区间总收益（Total Return）

```
总收益 = 期末净值 / 期初净值 - 1
```

易方达消费（110022）从 2010-08-19 到 2026-10-26：
`2.79 / 1.0 - 1 = +179%`

**注意**：这个数字包含分红吗？不包含（用的是单位净值）。
要看含分红的真实收益，应该用**累计净值**（`acc_nav`）。
我们的接口提供了 `use_acc_nav=True` 参数来切换。

### 2. 年化收益（Annualized Return）

```
年化收益 = (1 + 总收益) ^ (252 / 交易日数) - 1
```

**为什么用 252？** A股一年约 244-250 个交易日，金融界统一约定用 **252**。

**为什么需要年化？** 因为区间长度不同不能直接比：
- 基金A：3年赚 30%
- 基金B：10年赚 80%

谁厉害？年化后：A ≈ 9.1%/年，B ≈ 6.1%/年 → A 更好。

易方达消费 16 年总收益 179% → 年化 **6.83%**

## 三、风险类指标

### 3. 年化波动率（Volatility）—— 风险的数学定义

```
年化波动率 = 日收益率的标准差 × √252
```

**标准差**衡量"数字上下跳动的剧烈程度"。
乘以 √252 是因为：**方差随时间线性增长，标准差随时间开方增长**。

| 波动率 | 含义 |
|---|---|
| < 10% | 很稳（货币基金、短债） |
| 10-20% | 稳健（平衡型、宽基指数） |
| 20-30% | 较波动（股票型） |
| > 30% | 高风险（行业主题、单一赛道） |

易方达消费：**22.49%** → 典型股票型基金。

### 4. 最大回撤（Max Drawdown）—— 最该看的指标

```
回撤序列 = 当前净值 / 历史最高净值 - 1
最大回撤 = 回撤序列的最小值
```

例子：
```
净值: 1.0 → 1.2 → 0.9
最高点: 1.2
回撤 = 0.9 / 1.2 - 1 = -25%
```

**为什么说这是最重要的指标？**

因为它直接决定"你能不能拿得住"。
回撤 50% 意味着 100 万变 50 万。大多数人在这个位置会崩溃割肉，
于是"账面亏损"变成"真实亏损"，从此错过反弹。

易方达消费：**-57.32%** —— 意思是历史上最惨的时候接近腰斩。
看到这个数字，客户就该明白：这不是一个"稳赚"的产品。

### 5. 日胜率（Win Rate）

```
胜率 = 上涨天数 / 总交易日数
```

易方达消费：**49.1%** —— 有意思的结论：
**赚钱的基金，胜率也可能不到 50%**。因为少数大涨的日子贡献了大部分收益。

## 四、风险调整收益指标（专业选手看这些）

### 6. 夏普比率（Sharpe Ratio）

```
夏普 = (年化收益 - 无风险利率) / 年化波动率
```

**通俗理解**：每承担 1 单位风险，换来多少超额收益。

无风险利率我们取 **2%**（近似一年期国债）。

| 夏普 | 评价 |
|---|---|
| < 0 | 还不如存银行 |
| 0 ~ 1 | 一般 |
| 1 ~ 2 | 不错 |
| > 2 | 优秀（但要警惕回测过拟合） |

易方达消费：**(6.83% - 2%) / 22.49% = 0.21** → 一般。

### 7. 索提诺比率（Sortino Ratio）

```
索提诺 = (年化收益 - 无风险利率) / 下行波动率
```

**和夏普的区别**：只统计"下跌"的波动，不惩罚上涨。

**为什么更合理**：夏普把"暴涨"也算作风险（因为波动大），
但从投资者角度，暴涨是好事不是风险。索提诺修正了这个逻辑缺陷。

### 8. 卡玛比率（Calmar Ratio）

```
卡玛 = 年化收益 / |最大回撤|
```

**通俗理解**：为了赚这些钱，你最多要忍受多大痛苦。

| 卡玛 | 评价 |
|---|---|
| < 0.5 | 一般 |
| 0.5 ~ 1 | 不错 |
| > 1 | 优秀 |

易方达消费：6.83% / 57.32% = **0.12** → 说明"赚的钱远不够补偿承受的痛苦"。

## 五、综合评分模型（产品的差异化卖点）

单个指标客户看不懂，需要合成一个 0-100 的分数。

### 权重设计

| 维度 | 权重 | 理由 |
|---|---|---|
| 收益能力 | 40% | 客户最关心"能赚多少" |
| 风险控制 | 30% | 决定"能不能拿得住" |
| 风险调整收益 | 30% | 专业视角的性价比 |

### 打分方式：分段线性映射

把指标值压缩到 0-100 区间：

| 指标 | 0分 | 100分 |
|---|---|---|
| 年化收益 | -10% | +30% |
| 最大回撤 | -50% | 0% |
| 夏普比率 | -1 | +2.5 |

计算示例（易方达消费）：
```
收益得分 = (6.83% - (-10%)) / (30% - (-10%)) × 100 = 42.1 → 实际按公式算
回撤得分 = (-57.32% 超出 -50% 下限) → 0 分
夏普得分 = (0.21 - (-1)) / (2.5 - (-1)) × 100 = 34.6
总分 = 42.1×0.4 + 0×0.3 + 34.6×0.3 ≈ 27.2 分 → "较差"
```

### 等级划分

| 分数 | 等级 |
|---|---|
| ≥ 80 | 优秀 |
| 65-80 | 良好 |
| 50-65 | 一般 |
| < 50 | 较差 |

> ⚠️ **合规提醒**：这个评分是"历史数据的统计结果"，
> 界面上必须配合免责声明，不能说成"推荐买入"。
> 权重数值可以按业务需求调整，但每次调整都要重新评估合规风险。

## 六、单元测试：怎么保证算得对

`tests/test_indicators.py` 里有 13 个测试，核心思路是**喂已知答案**：

```python
def test_max_drawdown_simple(self):
    """1.0 -> 1.2 -> 0.9，回撤应该是 -25%"""
    nav = make_nav([1.0, 1.2, 0.9])
    self.assertAlmostEqual(indicators.max_drawdown(nav), -0.25, places=6)
```

实测结果：**13 个测试全部通过**。

还有一个特别有价值的测试：

```python
def test_good_fund_beats_bad_fund(self):
    """稳健上涨的基金，评分必须高于暴涨暴跌的基金"""
```

这个测试保护的是**业务逻辑**：如果哪天有人改权重改出 bug，
导致"垃圾基金得高分"，测试会立刻报警。这比测试单个公式更重要。
