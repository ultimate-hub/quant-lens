## 一、P7 选股筛选器

### 1.1 解决什么问题

单只股票分析回答"这个好不好"，筛选器回答"**在所有候选里，哪几只最好**"。

### 1.2 候选池

内置 30 个板块、91 只代表个股（`app/news/sector_map.py`）：

```
全部板块（91只）
├── 半导体    中芯国际、北方华创、韦尔股份、中微公司、紫光国微
├── 固态电池  宁德时代、国轩高科、欣旺达、孚能科技
├── 白酒      贵州茅台、五粮液、泸州老窖、山西汾酒
└── ... 共30个板块
```

也可以只选某个板块（如"白酒"→4只）。

### 1.3 筛选条件（6 个）

| 条件 | 说明 | 示例 |
|---|---|---|
| PE 上限 | 估值不能太贵 | 30 |
| ROE 下限 | 盈利能力门槛 | 15% |
| 市值下限 | 排除小盘股 | 100亿 |
| 3月动量下限 | 趋势要求 | 0% |
| 最大回撤上限 | 风险容忍度 | -40% |
| 综合分下限 | 直接按评分筛 | 55 |

留空 = 不限。条件之间是 **AND** 关系。

### 1.4 性能设计（关键）

单只标的需要 1-3 次网络请求（K线 + 快照 + 财务），约 0.5-1 秒。
91 只串行要 1.5 分钟，用户会以为卡死。

**解法：线程池并发（8 个 worker）**

```
实测：91 只全量评估 13.2 秒，0 失败
```

**为什么筛选时不调 AI**：
AI 分析一只股票要 3-10 秒且花钱。91 只就是 10-15 分钟 + 一笔费用。
所以筛选只做量化计算，用户点开某只股票时才调 AI。

### 1.5 实测结果

条件：ROE > 15%（均衡型模式）

```
候选 91 只 → 成功评估 91 只 → 命中 12 只

药明康德   603259.SH  76.7 良好  PE 16.3  ROE 22.4%  动量 +12.1%  回撤 -77.1%
陕西煤业   601225.SH  71.6 良好  PE 12.3  ROE 16.7%  动量  +6.7%  回撤 -33.1%
中国人寿   601628.SH  69.7 良好  PE  4.0  ROE 21.1%  动量 -15.3%  回撤 -52.6%
紫金矿业   601899.SH  66.5 ...
```

点击任意一行 → 直接跳到该股的详细分析页。

### 1.6 一个设计取舍

药明康德最大回撤 **-77.1%**，却排在第一名。
为什么？因为"均衡型"模式下风险维度只占 15% 权重，而它的质量分（89.2）和动量分（81.8）极高。

**这不是 bug，是权重的必然结果**。想看回撤小的，切到"低波型"模式或加"最大回撤上限"条件。

### 2.2 扩展指标清单

**统计特征（7个）**

| 指标 | 公式/含义 | 怎么看 |
|---|---|---|
| Hurst指数 | R/S 分析法 | >0.5 趋势持续，<0.5 均值回归 |
| 收益自相关 | 今日收益 vs 昨日 | >0 动量效应，<0 反转效应 |
| 方差比(5日) | 5日方差/(5×日方差) | >1 趋势性，<1 均值回归 |
| 均值回归半衰期 | AR(1) 回归推算 | 偏离后回到一半要几天 |
| JB统计量 | 偏度²+峰度² 组合 | 越大越偏离正态 |
| 最长连涨 | 连续上涨天数 | 情绪极端程度 |
| 最长连跌 | 连续下跌天数 | 恐慌程度 |

**技术指标（11个）**

| 指标 | 含义 |
|---|---|
| KDJ (K/D/J) | A股最常用超买超卖，K>80超买 |
| 布林 %B | >1 突破上轨，<0 跌破下轨 |
| 布林带宽 | 极窄=波动收敛，预示变盘 |
| ADX / ±DI | >25 强趋势，<20 震荡市 |
| OBV 能量潮 | 量价是否配合（背离预警） |
| CCI(20) | >100 强势，<-100 弱势 |
| Williams %R | >-20 超买，<-80 超卖 |
| 量比 | >1.5 放量，<0.7 缩量 |
| Amihud 非流动性 | 越大越难买卖（需成交额数据） |

**相对基准（4个）**

| 指标 | 含义 |
|---|---|
| 相关系数 | 与基准同涨同跌程度 |
| R² | 基准能解释多少波动（越低越独立） |
| 上行捕获率 | 基准涨1%，标的涨多少% |
| 下行捕获率 | 基准跌1%，标的跌多少% |

**行为特征（8个）**

| 指标 | 含义 |
|---|---|
| 最强/最弱月份 | 季节性效应 |
| 最强/最弱星期 | 星期效应 |
| 疼痛指数 | 回撤深度的均方根（比最大回撤全面） |
| 恢复因子 | 总收益 / 最大回撤 |
| 尾部比率 | 95分位收益 / 5分位损失 |
| M²测度 | 波动率调整后的收益 |

### 2.3 茅台实测数据（部分）

```
Hurst指数        0.997   ← 强趋势性
收益自相关       -0.007  ← 几乎无记忆
方差比(5日)      1.038   ← 略偏趋势
均值回归半衰期   113.5天
JB统计量         914.04  ← 严重偏离正态（厚尾）
最长连涨         7天
最长连跌         11天

布林 %B          0.727
ADX              48.5    ← 强趋势（>25）
OBV              量价齐升
CCI(20)          79.55
Williams %R      -25.84
量比             1.218

R²               0.370   ← 基准只能解释37%波动
上行捕获率       0.922   ← 涨得比大盘少
下行捕获率       0.818   ← 跌得也比大盘少

```

**这组数据能读出什么**：
- ADX 48.5 + Hurst 0.997 → 当前是明确趋势行情
- 上行捕获 0.92 / 下行捕获 0.82 → 比大盘更抗跌但也涨得慢（典型大盘蓝筹）
- JB 914 → 收益分布严重厚尾，"用标准差衡量风险不够"

### 2.4 开发中修的一个 bug

**Hurst 算出 1.019**，超出理论范围 [0,1]。

**原因**：R/S 分析法在短样本/强趋势下会高估。这是该方法的已知局限，不是代码错误。

**修复**：钳制到 [0,1]，并在文档里说明这个局限。
